# 财务 ERP 公司端

独立公司端前端（Vite + React + Ant Design）。管理端不在本仓库范围内。

## 本地启动

```bash
npm install
npm run dev
```

默认 http://localhost:5174 （避免与管理端 5173 冲突）。

## 演示账号

- 公司：`快乐智豪厦门文化有限公司`
- 账号：`ZH01`
- 密码：`625777`

账号、密码按字符串严格匹配（区分大小写，不自动去掉空格）。已注销机构无法登录。

## 功能

- 学员档案：搜索、详情、新生报名、报名、考勤、当天记录作废
- 业绩报表 / 课耗报表：日期筛选、排序、导出真实 xlsx

数据为内存 Mock，刷新页面后恢复初始数据。
