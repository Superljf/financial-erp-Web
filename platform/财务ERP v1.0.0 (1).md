# 3 需求分析
+ 系统划分为两个端口：
    - 管理端：面向平台管理员，负责公司（机构）主数据维护与财务源数据按月/按机构导入。
    - 公司端：面向机构用户，凭「公司名称 + 专用密码」登录，仅可查看本机构学员档案与业绩/课耗报表。
+ 角色与权限边界：
    - 管理端默认以「管理员」身份进入，可访问公司管理与数据管理全部能力；
    - 公司端以登录机构身份进入，顶部徽标显示机构名称，仅能操作本机构数据，登录态由专用密码校验。

### 5.1.1 公司列表

1）进入管理端默认落地「公司管理」页；页面顶部为统一导航（见 5.3.2），主区域为一张公司列表卡片。

2）筛选条件：

+ 纳税人识别号：
    - 文本输入框；
    - 提示语：纳税人识别号；
    - 输入后与列表「纳税人识别号」做包含匹配。
+ 公司名称：
    - 文本输入框；
    - 提示语：公司名称；
    - 输入后与列表「公司名称」做包含匹配。
+ 两个筛选条件为「或」关系：任一字段包含关键词即命中。

3）查询：点击按钮，根据筛选条件过滤列表数据，并更新列表计数文案「共 N 家公司（已按纳税人识别号/公司名称过滤）」。

4）重置：点击按钮，清空两个输入框与筛选条件，恢复全部公司列表。

5）公司列表：

+ 数据：当前管理端下的全部公司（机构）主数据；搜索筛选后仅展示命中项。
+ 排序：默认按 id 升序排列。
+ 分页：默认 10 条数据每页。
+ 显示：id、纳税人识别号、公司名称、专用账号、专用密码（掩码）、登记状态、成立日期、注销日期。
    - 专用密码：默认掩码「••••••」，固定列宽 160px（含眼睛图标），眼睛图标点击切换明文/掩码；
    - 登记状态：根据注销日期派生，有注销日期=「已注销」（黄圆圈），无注销日期=「存续」（蓝圆圈）；
    - 注销日期：为空时显示「-」。
+ 列固定：列表整体宽度可能超过管理端容器宽度（容器 max-width 1180px、列表固定列宽合计 1132px + 内边距），超出时容器横向滚动；操作列采用 position: sticky 固定于右侧、始终可见，固定列带左侧阴影提示可滚动。
+ 操作：点击「编辑」链接，弹出编辑公司弹窗（见 5.1.3）。

### 5.1.2 新增公司
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/209175/1786775228662-7daeb0b0-d2f5-493f-9844-1d6c04dea24e.png)

1）点击列表工具栏「+ 新增公司」按钮，弹出新增公司弹窗。

2）弹窗字段：

+ 纳税人识别号：
    - 必填；
    - 文本输入框；
    - 提示语：请输入纳税人识别号；
+ 公司名称：
    - 必填；
    - 文本输入框；
    - 提示语：请输入公司名称；
    - 约束：仅允许中文（不含字母、数字、符号、空格）；
+ 专用账号：
    - 必填；
    - 文本输入框；
    - 提示语：请输入专用账号（最多20个字符）；
    - 约束：最长 20 个字符；
+ 专用密码：
    - 必填；
    - 文本输入框；
    - 提示语：请输入6-16位字符作为公司端登录密码；
+ 成立日期：
    - 必填；
    - 日期选择器；
    - 提示语：yyyy-mm-dd；
+ 注销日期：
    - 非必填；
    - 日期选择器；
    - 留空表示「存续」；

3）保存按钮与校验：

+ 保存按钮默认置灰（disabled）不可点击；仅当所有必填项（纳税人识别号、公司名称、专用账号、专用密码、成立日期）均填写完整时，按钮才亮起可点击。
+ 失焦校验（实时）：每个必填字段失去焦点（blur）时校验是否已填写；未填写则输入框标红，并在错误区提示「XX不能为空」；填写后自动清除标红与提示。公司名称若已填写但不满足「仅允许中文」，则标红并提示「公司名称仅允许中文」。
+ 点击保存时校验（仅保留非填写类的复杂校验）：
    - 公司名称仅允许中文：提示语：公司名称仅允许中文；
    - 纳税人识别号已存在（与现有公司唯一键冲突）：提示语：纳税人识别号已存在，请核对；（**唯一性校验**）
    - 注销日期早于成立日期：提示语：注销日期不得早于成立日期。
+ 注：必填项「不能为空」已由失焦校验拦截，保存按钮在必填未完成时本就不可点击；上述点击时校验为兜底 + 重复/逻辑类校验。

4）保存成功：

+ 新公司 id = 当前最大 id + 1；
+ 登记状态默认为「存续」（注销日期留空）；
+ 关闭弹窗、列表刷新、Toast 提示：新增成功，已生成登录身份。

5）取消：点击按钮，关闭弹窗，不落库。

### 5.2.5 下载导入模板
1）点击「下载导入模板」生成**真正的 Excel 文件**（`.xlsx`，OOXML 格式），内含「账户表 / 出纳表 / 课耗表」三个工作表，每个工作表含表头与一行示例数据；文件名形如「汇总数据导入模板YYYYMMDDHHmmss.xlsx」。

2）模板含三张表，每张表的字段格式与示例如下（字段均为必填；金额类统一 2 位小数、单位元；三表须齐备；不含系统 id 列）：

**① 账户表（15 列）**

+ 年月：文本，格式 `YYYY-MM`；示例 `2026-08`
+ 公司名称：文本，仅中文（不含字母、数字、符号、空格）；示例 `快乐智豪厦门文化有限公司`
+ 纳税人识别号：文本，18 位统一社会信用代码；示例 `91350200MA8R5X2X9K`
+ 类型：文本，固定枚举 `预收学费`；示例 `预收学费`
+ 学员编号：文本；示例 `XYBH_20260813100000`（历史数据可能非 `XYBH` 开头，导入时不做格式限制）
+ 学生姓名：文本，仅中文，2~20 位；示例 `李宜栩`
+ 学生年级：文本，枚举（幼儿园小班~高三）；示例 `高三`
+ 上月剩余：数值，2 位小数；示例 `1500.00`
+ 应付：数值，2 位小数；示例 `0.00`
+ 转出：数值，2 位小数；示例 `0.00`
+ 预收：数值，2 位小数；示例 `6800.00`
+ 退款：数值，2 位小数；示例 `0.00`
+ 理赔：数值，2 位小数；示例 `0.00`
+ 课耗：数值，2 位小数；示例 `2600.00`
+ 本月剩余：数值，2 位小数；示例 `5700.00`

**② 出纳表（20 列）**

+ 年月：文本，`YYYY-MM`；示例 `2026-08`
+ 公司名称：文本，仅中文；示例 `快乐智豪厦门文化有限公司`
+ 纳税人识别号：文本，18 位统一社会信用代码；示例 `91350200MA8R5X2X9K`
+ 交易日期：日期，`YYYY-MM-DD`；示例 `2026-08-15`
+ 交易渠道：文本，枚举（C扫B / H5 / 刷卡 / 现金 / 转账）；示例 `C扫B`
+ 交易金额：数值，2 位小数（退款可为负，故不限制 >0）；示例 `6800.00` 或 `-980.00`
+ 清算金额：数值，2 位小数；示例 `6800.00`
+ 手续费：数值，2 位小数；示例 `0.00`
+ 团队：文本，可为空；示例 `厦门地区个性化团队`
+ 业务校区：文本，可为空；示例 `厦门帝豪个性化校区`
+ 学生姓名：文本，仅中文，2~20 位；示例 `李宜栩`
+ 学员编号：文本；示例 `XYBH_20260813100000`（历史数据可能非 `XYBH` 开头，导入时不做格式限制）
