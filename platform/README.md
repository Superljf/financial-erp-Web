# 财务 ERP 管理端

独立管理端前端（Vite + React + Ant Design）。原型 HTML 中的公司端不在本仓库范围内。

## 本地启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 http://localhost:5173）。

## 演示账号

- 账号：`admin`
- 密码：`625777`

账号、密码按字符串严格匹配（区分大小写，不自动去掉空格）。

## 功能

- 公司管理：机构主数据列表、筛选、新增、编辑
- 数据管理：按月份上传 Excel（账户表 / 出纳表 / 课耗表）、按公司查看导入状态、下载模板与原文件快照

数据为内存 Mock，刷新页面后恢复初始数据。
