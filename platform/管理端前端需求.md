## 1. 目标与边界

管理端面向平台管理员，负责两件事：

1. **公司（机构）主数据维护**：新增、编辑、列表检索。
2. **财务源数据按月导入**：上传 Excel（账户表 / 出纳表 / 课耗表），按月份或按公司查看导入状态，下载原文件与导入模板。

**不在本期管理端范围内：**

- 公司端登录、学员档案、报名 / 考勤、业绩报表、课耗报表。
- 管理端独立登录页：进入管理端默认以「管理员」身份落地，无需账号密码。

**与公司端的关键契约（管理端必须保证）：**

- 公司「专用账号 + 专用密码」是公司端登录凭证；管理端新增 / 编辑时必须可维护。
- 按月份下载的 Excel 是**导入当时的原始三表快照**，不含公司端后续「新生报名 / 学员考勤」写入的数据。

## 3. 全局前端规范

### 3.1 布局

| 项 | 口径 |
| --- | --- |
| 页面背景 | 浅灰底 `#f5f7fa`，主内容白卡片 |
| 内容容器 | `max-width: 1180px`，水平居中 |
| 顶部导航 | 高度 60px，白底，底部 1px 分割线，`position: sticky` |
| 主字体 | PingFang SC / Microsoft YaHei，正文 14px |
| 主色 | `#1677ff`（状态圆圈已导入 / 存续使用 `#157CFF`） |
| 弹窗宽度 | 默认 520px；遮罩 `rgba(15,30,60,.45)` |

### 3.2 顶部导航（管理端框架）

进入管理端后，所有页面共用同一套顶栏：

| 区域 | 内容 |
| --- | --- |
| 左侧标题 | 「管理端」 |
| 内联菜单 | 「公司管理」「数据管理」；当前项高亮下划线 |
| 右侧徽标 | 「管理员」 |
| 右侧操作 | 「退出」 |

**退出：** 清空管理端页面状态，返回端口选择首页（不是公司端登录页）。

**菜单切换：** 点击即切换主区域，不整页重载；切换时保留各页已有筛选条件（年份、搜索关键词、分页）由前端会话持有即可。

### 3.3 通用交互

| 组件 | 要求 |
| --- | --- |
| 主按钮 | 蓝底白字；未满足可提交条件时 `disabled` 置灰 |
| 次按钮 | 白底灰边（查询旁的重置、取消、下载模板） |
| 链接按钮 | 列表「编辑」使用文字链接 + 编辑图标 |
| Toast | 顶部居中浮层；成功绿边、失败红边；用于新增成功 / 保存成功 / 导入成功 / 校验失败 |
| 弹窗关闭 | 「取消」、右上角 ×、不落库 |
| 日期选择器 | 自定义日历；展示格式 `yyyy-mm-dd`；支持清除、今天、上/下月 |
| 分页 | 默认每页 10 条；展示「共 N 条记录 / 当前页 / 总页」；支持上一页、下一页、页码跳转 |
| 空态 | 表格无数据时居中文案（如「无匹配公司」） |

### 3.4 端口选择首页（进入管理端的前置页）

虽属两端共用入口，管理端必须实现：

- 标题：「财务 ERP 系统」
- 副标题：「前端交互原型 · 请选择进入端口」（正式环境可改为产品副标题，交互不变）
- 两张入口卡：
  - **管理端**：副文案「公司管理、数据管理」；点击进入管理端，默认落地公司管理。
  - **公司端**：不在本文展开。

## 4. 公司管理

进入管理端默认落地本页。主区域为一张公司列表卡片。

### 4.1 列表工具栏

从左到右：

1. 纳税人识别号输入框（placeholder：`纳税人识别号`）
2. 公司名称输入框（placeholder：`公司名称`）
3. 「查询」主按钮
4. 「重置」次按钮
5. 右侧「+ 新增公司」主按钮

### 4.2 筛选规则

| 项 | 口径 |
| --- | --- |
| 纳税人识别号 | 与列表「纳税人识别号」做**包含匹配** |
| 公司名称 | 与列表「公司名称」做**包含匹配** |
| 组合关系 | **或**：任一字段包含关键词即命中 |
| 查询 | 按当前两个输入框过滤列表，分页回到第 1 页；计数文案变为「共 N 家公司（已按纳税人识别号/公司名称过滤）」 |
| 重置 | 清空两个输入框与筛选条件，恢复全部公司，分页回到第 1 页 |
| 未筛选时计数 | 「共 N 家公司」 |

### 4.3 列表

| 项 | 口径 |
| --- | --- |
| 数据 | 当前管理端下全部公司主数据；筛选后仅展示命中项 |
| 排序 | 默认按 `id` 升序 |
| 分页 | 默认 10 条 / 页 |
| 横向滚动 | 容器 `max-width: 1180px`，列宽合计可能超出；表格区域允许横向滚动 |
| 操作列固定 | 「操作」列 `position: sticky; right: 0`，始终可见，左侧带阴影提示可滚动 |

**列定义：**

| 列 | 展示规则 | 建议列宽 |
| --- | --- | --- |
| id | 系统主键，数字 | 56px |
| 纳税人识别号 | 原文；超长省略，`title` 展示全文 | 200px |
| 公司名称 | 原文；超长省略，`title` 展示全文 | 220px |
| 专用账号 | 原文；空则 `-` | 110px |
| 专用密码 | 默认掩码 `••••••`；固定列宽 **160px**（含眼睛图标）；点击眼睛切换明文 / 掩码 | 160px |
| 登记状态 | **派生字段，不入库**：有注销日期 = 「已注销」（黄圆圈 `#FFB900`）；无注销日期 = 「存续」（蓝圆圈 `#157CFF`） | 100px |
| 成立日期 | `YYYY-MM-DD` | 120px |
| 注销日期 | 有值展示日期；为空显示 `-` | 120px |
| 操作 | 「编辑」链接，点击打开编辑弹窗 | 96px，sticky 右侧 |

### 4.4 新增公司弹窗

**触发：** 工具栏「+ 新增公司」。

**标题：** 「新增公司」。

**字段：**

| 字段 | 必填 | 控件 | Placeholder | 约束 |
| --- | --- | --- | --- | --- |
| 纳税人识别号 | 是 | 文本 | 请输入纳税人识别号 | 非空 |
| 公司名称 | 是 | 文本 | 请输入公司名称 | 仅允许中文（不含字母、数字、符号、空格） |
| 专用账号 | 是 | 文本 | 请输入专用账号（最多20个字符） | 最长 20 个字符 |
| 专用密码 | 是 | 文本 | 请输入6-16位字符作为公司端登录密码 | 6–16 位字符 |
| 成立日期 | 是 | 日期选择器 | yyyy-mm-dd | 非空 |
| 注销日期 | 否 | 日期选择器 | yyyy-mm-dd | 留空表示存续 |

成立日期、注销日期同一行并排。必填项标签带红色 `*`。

**保存按钮态：**

- 默认 `disabled`。
- 仅当必填项全部填写完整后亮起：纳税人识别号、公司名称、专用账号、专用密码、成立日期。

**失焦校验（实时）：**

| 时机 | 规则 | 提示 |
| --- | --- | --- |
| 必填字段 blur 且为空 | 输入框标红 | `XX不能为空`（如「公司名称不能为空」） |
| 公司名称已填但含非中文 | 输入框标红 | `公司名称仅允许中文` |
| 填写合法后 | 清除该字段标红与对应提示 | — |

**点击保存时校验（复杂 / 兜底）：**

| 顺序 | 规则 | 提示 |
| --- | --- | --- |
| 1 | 公司名称仅允许中文 | 公司名称仅允许中文 |
| 2 | 纳税人识别号与已有公司冲突（唯一键） | 纳税人识别号已存在，请核对 |
| 3 | 注销日期早于成立日期 | 注销日期不得早于成立日期 |

必填为空已由按钮置灰 + 失焦校验拦截，保存点击以唯一性、中文、日期逻辑校验为主。

**保存成功：**

- 新公司 `id` = 当前最大 id + 1（若后端生成则以前端展示刷新后的 id 为准）。
- 注销日期留空 → 登记状态「存续」。
- 关闭弹窗、刷新列表、Toast：`新增成功，已生成登录身份`。

**取消：** 关闭弹窗，不落库。

### 4.5 编辑公司弹窗

**触发：** 列表行「编辑」。

**标题：** 「编辑公司」。打开时带入当前行数据。

**字段：**

| 字段 | 可编辑 | 必填 | 说明 |
| --- | --- | --- | --- |
| id（系统主键） | 否 | — | `disabled` 只读 |
| 纳税人识别号（业务键） | 否 | — | `disabled` 只读；编辑不做唯一性校验 |
| 公司名称 | 是 | 是 | 预填；仅允许中文 |
| 专用账号 | 是 | 是 | 预填；最长 20 字符 |
| 专用密码 | 是 | 是 | 预填明文值，输入框以掩码展示，可修改 |
| 成立日期 | 是 | 是 | 预填 |
| 注销日期 | 是 | 否 | 有则预填；填值后登记状态变为「已注销」 |

**保存按钮态：**

- 必填项：公司名称、专用账号、专用密码、成立日期均非空才可点击。
- 打开时字段已预填，保存按钮默认亮起。

**失焦校验：** 同新增（必填为空、公司名称仅中文）。

**点击保存时校验：**

| 规则 | 提示 |
| --- | --- |
| 公司名称仅允许中文 | 公司名称仅允许中文 |
| 注销日期早于成立日期 | 注销日期不得早于成立日期 |

**保存成功：** 更新该行、关闭弹窗、刷新列表、Toast：`保存成功`。

**取消：** 关闭弹窗。

## 5. 数据管理

### 5.1 视图切换与年份

页顶部两个子页签：

| 页签 | 默认 | 说明 |
| --- | --- | --- |
| 按月份 | 是 | 可上传 / 重新上传、下载原文件、下载模板 |
| 按公司 | 否 | 只读矩阵，不可点击上传 |

**年份选择：** 下拉单选，选项 `2024 / 2025 / 2026`，默认 `2026`。切换年份立即刷新当前视图，无需点查询。

两个页签共用同一年份；切换页签不重置年份。

### 5.2 按月份视图

**数据：** 当前选中年份的 1–12 月导入概览。

**排序：** 月份升序（1 月 → 12 月）。

**分页：** 默认 10 条 / 页（12 个月会分成两页）。

**筛选条：** 左侧「查询年份」下拉；右侧「下载导入模板」。

**列定义：**

| 列 | 宽度 | 已导入 | 未导入 |
| --- | --- | --- | --- |
| 月份 | 约 80px，左对齐 | `N月` | `N月` |
| Excel 源文件 | 约 170px | 可点击 file-pill（Excel 图标 + 文件名）；长文件名省略号 | `-`；若该月未正式上传但已有数据，仍展示可下载 pill，文件名为 `原excel数据_YYYY-MM.xlsx` |
| 上传时间 | 约 170px | `YYYY-MM-DD HH:mm:ss` | `-` |
| 导入状态 | 约 120px | 蓝圆圈 `#157CFF` + 「已导入」 | 灰圆圈 `#999999` + 「未导入」 |
| 操作 | 约 140px | 「重新上传」次按钮 | 「上传」主按钮 |

**操作：**

1. **上传 / 重新上传：** 弹出「上传数据 · N月」弹窗。
2. **点击 file-pill：** 下载该月**上传当时的原始 Excel**（三表快照），真实 `.xlsx`，工作表名为「账户表 / 出纳表 / 课耗表」。
   - 文件名沿用该月源文件名。
   - 未正式上传但已有该月数据：文件名 `原excel数据_YYYY-MM.xlsx`。
   - **不含**公司端会话内后续报名 / 考勤写入的数据。
3. **下载导入模板：** 见 5.4。

### 5.3 按公司视图

**形态：** 「公司 × 12 月」矩阵。

| 项 | 口径 |
| --- | --- |
| 首列 | 机构名称，固定 |
| 表头 | 「公司 ＼ 月份」+ 1月 ~ 12月 |
| 行高 | 数据行锁定 40px，矩阵不因内容跳动 |
| 可滚动 | 矩阵区域可横向 / 纵向滚动（建议 `max-height: 520px`） |

**单元格状态：**

| 展示 | 含义 |
| --- | --- |
| 绿底对勾 ✓ | 已导入：该公司该月「账户表」数据已导入 |
| 灰圆圈 ○ | 未导入 |
| 空白 | 该公司该月尚未注册（成立日期晚于该月）或已注销（注销日期早于该月），不展示导入状态 |

**交互约束：**

- 格子只读，**不可点击上传**。
- 状态与「按月份」视图同步：同一机构同一月份两视图一致。
- 本页不展示「下载导入模板」（模板入口仅在按月份筛选条与上传弹窗内）。

### 5.4 上传数据弹窗

**触发：** 按月份视图的「上传」或「重新上传」。

**标题：** `上传数据 · N月`。

**内容结构：**

1. 说明文案：请选择 Excel 文件（`.xlsx` / `.xls`），每次仅 1 个文件，覆盖当月数据。
2. 美化文件选择器 `.file-picker`：
   - 「选择文件」按钮打开系统文件框。
   - 仅接受单文件 `.xlsx / .xls`。
   - 选中后展示文件名；未选时展示「未选择任何文件」。
3. 校验规则说明区（只读）：
   - 工作簿须含「账户表 / 出纳表 / 课耗表」三张。
   - 表头必须与导入模板一致。
   - 所有字段必填；数据源年月 = 当月。
   - 纳税人识别号需匹配系统中的公司（存续 / 已注销均可导入）。
4. 「下载导入模板（标准表头）」链接，规则同 5.5。

**开始上传：**

| 结果 | 前端表现 |
| --- | --- |
| 未选择文件 | 提示：`请先选择 Excel 文件` |
| 校验失败 | 整批拒绝，不写入；列出失败原因（表头不一致 / 纳税人识别号无匹配 / 数据源年月≠当月 / 必填为空） |
| 校验通过 | 关闭弹窗、刷新列表、Toast：`导入成功（覆盖当月数据）` |

重新上传与首次上传同一套交互，成功后覆盖当月数据。

**取消：** 关闭弹窗。

> 原型演示曾用文件名含 `fail` 触发失败。正式实现必须按真实 Excel 内容校验，不以文件名为准。

### 5.5 下载导入模板

**入口：**

- 按月份视图筛选条右侧「下载导入模板」
- 上传弹窗内「下载导入模板（标准表头）」

**产物：**

- 真实 `.xlsx`（OOXML），不是 CSV / HTML 伪装。
- 三个工作表：账户表、出纳表、课耗表。
- 每个工作表：标准表头 + **一行示例数据**。
- **不含系统 id 列**。
- 文件名：`汇总数据导入模板YYYYMMDDHHmmss.xlsx`。

**模板字段（前端生成或由后端返回均可，字段必须一致）：**

金额类统一 2 位小数、单位元；字段默认必填，下表单独标注可空项。

#### 账户表（15 列）

| 字段 | 类型 / 约束 | 示例 |
| --- | --- | --- |
| 年月 | 文本 `YYYY-MM` | 2026-08 |
| 公司名称 | 文本，仅中文 | 快乐智豪厦门文化有限公司 |
| 纳税人识别号 | 文本，18 位统一社会信用代码 | 91350200MA8R5X2X9K |
| 类型 | 固定枚举 `预收学费` | 预收学费 |
| 学员编号 | 文本；导入不做 `XYBH` 前缀限制 | XYBH_20260813100000 |
| 学生姓名 | 文本，仅中文，2~20 位 | 李宜栩 |
| 学生年级 | 枚举：幼儿园小班 ~ 高三 | 高三 |
| 上月剩余 | 数值，2 位小数 | 1500.00 |
| 应付 | 数值，2 位小数 | 0.00 |
| 转出 | 数值，2 位小数 | 0.00 |
| 预收 | 数值，2 位小数 | 6800.00 |
| 退款 | 数值，2 位小数 | 0.00 |
| 理赔 | 数值，2 位小数 | 0.00 |
| 课耗 | 数值，2 位小数 | 2600.00 |
| 本月剩余 | 数值，2 位小数 | 5700.00 |

#### 出纳表（20 列）

| 字段 | 类型 / 约束 | 示例 |
| --- | --- | --- |
| 年月 | 文本 `YYYY-MM` | 2026-08 |
| 公司名称 | 文本，仅中文 | 快乐智豪厦门文化有限公司 |
| 纳税人识别号 | 文本，18 位统一社会信用代码 | 91350200MA8R5X2X9K |

## 9. 原文口径对齐说明

整理时按「可开发」口径做了如下对齐，不改变业务意图：

1. **编辑弹窗保存按钮：** 原文 5.1.3 写必填为「公司名称、专用密码、成立日期」，但同节「专用账号」亦为必填。本文按专用账号必填处理，与新增弹窗、原型实现一致。
2. **登记状态颜色：** 原文「已注销 = 黄圆圈」。原型 CSS 变量名虽为 `dot-gray`，实际色值为 `#FFB900`（黄）。前端按黄色实现。
3. **专用密码长度：** 原文 placeholder 写明 6–16 位，点击保存校验列表未单列。本文将其作为前端约束，避免与提示文案不一致。
4. **上传失败演示：** 原型用文件名含 `fail` 模拟失败；正式需求以 Excel 内容校验为准。
